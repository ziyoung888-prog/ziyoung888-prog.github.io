51单片机系统设计与嵌入式编程实践8051 Microcontroller System Design and Embedded C Practice

该项目基于“单片机原理及应用”课程材料，围绕 MCS-51 体系结构、Keil C51 编程和 Proteus VSM 仿真展开。项目覆盖外部中断优先级、定时器/计数器初值计算、UART 串行通信配置、HEX 固件生成和仿真调试流程，将 51 单片机硬件寄存器、C51 程序结构和外设控制逻辑连接为一个完整的嵌入式实验流程。 This academic laboratory project is based on the Microcontroller Principles and Applications course. It covers MCS-51 architecture, Keil C51 programming and Proteus VSM simulation, linking interrupt priority, timer/counter calculation, UART configuration, HEX firmware generation and simulated peripheral control into one embedded-system workflow.

项目叙事Project Story

项目背景Context

51 单片机实验需要把寄存器配置、C51 程序、I/O 端口和外设响应连接起来，判断硬件控制逻辑是否符合预期。The 8051 lab links register configuration, C51 code, I/O ports and peripheral response to check whether the control logic behaves as expected.

工程目标Objective

完成外部中断、定时器计数器和 UART 串行通信三类核心实验，并形成从代码到仿真的调试流程。The objective was to complete external interrupt, timer/counter and UART communication labs, forming a workflow from code to simulation debugging.

技术执行Action

使用 Keil C51 编写程序并生成 HEX 文件，在 Proteus 中搭建单片机最小系统和外围电路，验证 LED、按键和串口终端响应。Keil C51 was used to write code and generate HEX firmware, while Proteus was used to model the minimum system and verify LED, button and serial-terminal response.

关键结果Result

完成 10 个章节任务和 3 个综合实验，推导 50ms 定时初值 0x4C00 与 9600bps 串口重装初值 0xFD。The project completed ten course tasks and three integrated labs, including the 50ms timer preload 0x4C00 and 9600bps UART reload value 0xFD.

问题背景Problem Context

单片机应用系统需要同时理解硬件寄存器、外设时序、程序结构和电路连接。对于中断响应、定时输出和串行通信等常见场景，工程人员需要把寄存器配置、C 程序、I/O 端口和仿真结果对应起来，才能判断系统行为是否符合设计目标。Microcontroller applications require an understanding of registers, peripheral timing, program structure and circuit connections. Interrupt response, timed output and serial communication all require a clear mapping between register settings, C code, I/O ports and simulation behaviour.

技术流程Technical Workflow

阶段一Stage 1建立 Keil C51 工程，选择 AT89C51/STC89C52 目标芯片，编写 C51 源文件并生成 HEX 固件。Create a Keil C51 project, select the target AT89C51/STC89C52 device, write C51 source code and generate HEX firmware.
阶段二Stage 2在 Proteus 中绘制单片机最小系统和外围电路，加载 HEX 文件，观察 LED、按键和串口终端等外设响应。Draw the minimum microcontroller system and peripheral circuit in Proteus, load the HEX file and observe LED, button and serial-terminal responses.
阶段三Stage 3配置 INT0/INT1 外部中断、IE/IP 优先级和 ISR 程序，验证不同优先级中断对流水灯状态的影响。Configure INT0/INT1 external interrupts, IE/IP priority and ISR routines, then verify how interrupt priority changes LED sequence behaviour.
阶段四Stage 4基于 11.0592MHz 晶振计算定时器初值和 UART 波特率初值，用 TH0/TL0、TMOD、SCON、SBUF 等寄存器实现定时输出与 9600bps 串口收发。Calculate timer preload and UART reload values from an 11.0592MHz clock, using TH0/TL0, TMOD, SCON and SBUF for timed output and 9600bps serial communication.

技术工作Technical Contribution

  • 使用 C51 编写流水灯主程序、外部中断服务程序、定时器中断程序和串口收发函数。Wrote C51 routines for LED sequencing, external interrupt service, timer interrupts and UART send/receive functions.
  • 配置 EX0/EX1、IT0/IT1、PX0/PX1 等中断相关位，分析边沿触发与优先级对程序执行顺序的影响。Configured EX0/EX1, IT0/IT1 and PX0/PX1 settings to analyse edge-triggered interrupt behaviour and priority effects.
  • 根据 50ms 定时目标推导 TH0=0x4C、TL0=0x00，并在定时中断中手动重装初值。Derived TH0=0x4C and TL0=0x00 for a 50ms timing target and reloaded the timer values inside the interrupt routine.
  • 使用 T1 方式 2 自动重装产生 9600bps 波特率，配置 SCON、REN、TI/RI 标志位完成串口通信逻辑。Used Timer 1 mode 2 auto-reload to generate a 9600bps baud rate and configured SCON, REN, TI/RI flags for serial communication logic.

工具与方法Tools and Methods

  • 工具：Keil µVision C51、Proteus VSM、AT89/STC 系列 51 单片机、HEX 固件文件。Tools: Keil µVision C51, Proteus VSM, AT89/STC 8051-family microcontrollers and HEX firmware files.
  • 方法：寄存器配置、I/O 端口控制、外部中断、定时器初值计算、UART 波特率计算、仿真调试。Methods: register configuration, I/O control, external interrupts, timer preload calculation, UART baud-rate calculation and simulation debugging.

选定输出Selected Outputs

  • 外部中断实验：主程序 P1 口流水灯，INT0 触发全亮/全灭闪烁，INT1 触发高低 4 位交替显示。External interrupt lab: P1 LED sequence in the main loop, INT0 for all-on/all-off flashing and INT1 for high/low four-bit alternation.
  • 定时器实验：T0 方式 1 下使用 0x4C00 初值实现 50ms 定时，并通过计数累加实现周期输出。Timer lab: T0 mode 1 uses 0x4C00 preload for 50ms timing and counter accumulation for periodic output.
  • 串口实验：T1 方式 2 自动重装，TH1/TL1=0xFD，对应 11.0592MHz 晶振下 9600bps 串口通信。UART lab: T1 mode 2 auto-reload with TH1/TL1=0xFD for 9600bps serial communication with an 11.0592MHz crystal.
