EDA综合实践：交通信号灯控制器设计EDA Practice: FPGA Traffic Signal Controller Design

该项目基于 EDA 实践总结报告和答辩记录卡，使用 Vivado 与 Verilog HDL 完成基于 FPGA 的交通信号灯控制系统。设计对象为主干道与支干道交叉口，要求主干道通行 30 秒、支干道通行 20 秒、绿灯转红灯前黄灯亮 5 秒，并使用 LED 模拟红黄绿灯、七段数码管显示状态持续时间。项目中本人负责数码管显示模块、各模块功能调试和组合后的系统功能测试。This EDA practice project uses Vivado and Verilog HDL to implement an FPGA-based traffic signal controller. The system controls a main road and branch road, with 30s main-road passage, 20s branch-road passage and a 5s yellow-light transition, using LEDs for signal lights and seven-segment displays for countdown timing. My work covered the seven-segment display module, module debugging and integrated system testing.

项目叙事Project Story

项目背景Context

交通信号灯控制器需要把道路通行规则转化为可执行的时序逻辑，包括状态切换、倒计时显示和灯态输出。The traffic signal controller converts road-passage rules into executable timing logic, including state switching, countdown display and signal output.

工程目标Objective

实现主干道 30 秒、支干道 20 秒、黄灯 5 秒的周期控制，并通过 LED 和四位数码管同步展示系统状态。The objective was to implement 30s main-road timing, 20s branch-road timing and 5s yellow transition with LED and four-digit display output.

技术执行Action

使用 Vivado 与 Verilog HDL 完成数码管显示模块、状态切换逻辑、LED 输出控制和组合后的系统功能测试。Vivado and Verilog HDL were used for display logic, state switching, LED output control and integrated system testing.

关键结果Result

形成可解释的 FPGA 交通灯控制系统，答辩记录覆盖状态循环、动态扫描显示、位码变量和显示数据含义。The project produced an explainable FPGA traffic-light controller, with defence discussion covering state cycling, display scanning, digit selection and display data.

项目动机与岗位价值Project Motivation and Role Value

为什么要做Why this project

FPGA 项目训练的是硬件逻辑思维：系统行为不是按软件顺序逐行执行，而是由并行模块、时钟、状态机和信号同步共同决定。交通灯控制器足够简单，但能完整覆盖状态切换、计数、显示和板级验证。An FPGA project trains hardware-logic thinking: system behaviour is not sequential software execution but the result of parallel modules, clocks, FSMs and signal synchronisation. A traffic-light controller is simple enough to explain but complete enough to cover state transition, counting, display and board validation.

工程意义Engineering meaning

项目意义在于把真实规则转成可综合的数字电路。主干道、支干道、黄灯过渡和倒计时显示需要被拆成分频、计数、状态机、LED 输出和数码管扫描模块，体现数字系统模块化设计思路。The meaning is converting real-world rules into synthesizable digital logic. Main-road timing, branch-road timing, yellow transition and countdown display are decomposed into divider, counter, FSM, LED output and seven-segment scanning modules.

能力与岗位连接Ability and role connection

项目对应 FPGA 入门开发、嵌入式硬件验证、数字逻辑测试、自动化控制和硬件调试岗位。它强化了模块划分、时序意识、Verilog 表达、仿真检查和答辩解释硬件逻辑的能力。The project is relevant to entry-level FPGA development, embedded hardware verification, digital-logic testing, automation control and hardware debugging. It strengthens modular decomposition, timing awareness, Verilog expression, simulation checking and explaining hardware logic.

技术流程Technical Workflow

阶段一Stage 1拆分系统功能：分频模块、计数模块、LED 显示模块、数码管显示模块和顶层连接模块。Decompose the system into clock divider, counter, LED display, seven-segment display and top-level integration modules.
阶段二Stage 2使用 Verilog HDL 编写模块逻辑，采用 case 语句实现四个交通灯状态循环切换。Write module logic in Verilog HDL and use case statements to cycle through four traffic-signal states.
阶段三Stage 3实现数码管动态扫描显示：四位数码管不是同时点亮，而是在约 1kHz 扫描频率下依次循环点亮，视觉上呈现为同时显示。Implement dynamic seven-segment scanning: four digits are activated sequentially at around 1kHz, appearing simultaneous to the human eye.
阶段四Stage 4完成 Vivado 仿真、RTL 检查、比特流生成和 FPGA 开发板功能验证，并在答辩中解释状态切换和数码管变量。Run Vivado simulation, RTL checks, bitstream generation and FPGA board verification, then explain state switching and display variables during the defence.
